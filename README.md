# Comercio Seguro Escobar · demo

Prototipo del Grupo 2 (ingreso ITBA). Página que ve el vecino al escanear el sticker del cajón.
Datos, nombres y números de ejemplo.

- Página: `index.html` (CSS y JS adentro, sin frameworks).
- Modo alerta para la presentación: agregar `?alerta=1` al final de la URL.
- Para cambiar un texto: editar `index.html` en GitHub (ícono del lápiz) y guardar con "Commit changes". GitHub Pages lo publica solo en 1 o 2 minutos.
